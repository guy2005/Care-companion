# Care Companion (ผู้ช่วยร่วมเดินทางและทำธุระ)

**Care Companion** เป็นเว็บแอปพลิเคชันตัวกลางที่เชื่อมโยงระหว่าง **ผู้ที่ต้องการผู้ช่วยร่วมเดินทาง (Customer)** เช่น ผู้สูงอายุ หรือผู้ที่เดินทางคนเดียวไม่สะดวกไปทำธุระนอกบ้าน (เช่น ไปพบแพทย์ตามนัดที่โรงพยาบาล, ไปธนาคาร, ติดต่อหน่วยงานราชการ หรือไปซื้อสินค้า) กับ **ผู้ให้บริการร่วมเดินทาง (Companion)** ที่ผ่านการตรวจสอบเอกสารยืนยันตัวตน พร้อมระบบดูแลภาพรวมสำหรับ **Admin**

> ⚠️ **ข้อควรทราบ:** ผู้ร่วมเดินทาง (Companion) มีหน้าที่ช่วยเหลือและอำนวยความสะดวกในการเดินทางและการทำธุระเท่านั้น **ไม่ใช่ผู้ให้บริการทางการแพทย์หรือผู้ดูแลรักษาผู้ป่วย**

---

## 👥 บทบาทผู้ใช้งานในระบบ (Roles)

1. **Customer (ลูกค้า / ผู้ว่าจ้าง)**
   - ค้นหาและดูประวัติผู้ร่วมเดินทางที่ตรงตามความต้องการ
   - สร้างคำขอนัดหมายร่วมเดินทาง ระบุวัน เวลา จุดรับ-ส่ง พร้อมพิกัด GPS และแผนที่ Google Maps
   - ติดตามสถานะการเดินทางแบบ Real-time และให้คะแนนรีวิวหลังเสร็จสิ้นบริการ

2. **Companion (ผู้ร่วมเดินทาง)**
   - จัดการข้อมูลโปรไฟล์ ทักษะ พื้นที่ให้บริการ และอัตราค่าบริการต่อชั่วโมง
   - อัปโหลดเอกสารยืนยันตัวตน (บัตรประจำตัวประชาชน, ใบขับขี่, เอกสารรับรองประสบการณ์)
   - ตรวจสอบคำขอร่วมเดินทาง กดรับงาน/ปฏิเสธงาน และอัปเดตสถานะการเดินทาง

3. **Admin (ผู้ดูแลระบบ)**
   - ตรวจสอบเอกสารประจำตัวและอนุมัติผู้ร่วมเดินทาง (Companion Verification)
   - ติดตามภาพรวมการใช้งาน สถิติ และรายการนัดหมายทั้งหมดในระบบ

---

## 🌟 ฟีเจอร์หลัก (Key Features)

- **ค้นหาและคัดกรองผู้ช่วย:** คัดกรองตามหมวดหมู่ธุระ, พื้นที่ให้บริการ และคะแนนรีวิว
- **ระบบขอรับบริการเดินทาง:** ระบุรายละเอียดธุระ พร้อมปุ่มระบุพิกัด GPS อัตโนมัติและแผนที่นำทาง
- **ระบบตรวจสอบความปลอดภัย:** ตรวจสอบเอกสารยืนยันตัวตน 4 รายการก่อนเริ่มรับงาน
- **ระบบติดตามสถานะและการรีวิว:** ติดตามขั้นตอนการเดินทางและให้คะแนนดาวเพื่อความน่าเชื่อถือ
